# Multi-Vertical Earning Engine

AgentFlow separates earning operations into independent verticals coordinated by the CEO layer.

## Commerce
Deal research, compliant review/content drafting, affiliate link tracking and performance analytics. Publishing must respect each platform's rules and applicable advertising/affiliate disclosure requirements.

## Crypto
Research and tracking for legitimate zero-capital opportunities and task campaigns. The engine does not custody assets, request seed phrases/private keys, trade, withdraw, transfer or provide financial guarantees.

## Exchange read-only integration
Binance, Bybit and OKX are represented as read-only capability slots. Only API credentials with read/balance permissions should ever be configured. Withdrawal, transfer and trading permissions are explicitly unsupported.

## Revenue accounting
The current snapshot starts at zero and never fabricates revenue. Real revenue must come from verified payment/order events. Exchange balances are portfolio observations, not revenue.
