# AI Website inspection link

The Workflows dashboard provides a single fixed shortcut for the owner to inspect the live AI Website.

- Target: `https://agentflow-khaki-rho.vercel.app/website`
- Opens in a new tab.
- This shortcut does not change AI Website runtime or orchestration behavior.
- Future AI modules should expose their owner-facing inspection URL from the central dashboard rather than requiring separate bookmarks.
